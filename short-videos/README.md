# SHORT-VIDEOS — MPN

Iki gatandukanyirizo kirimwo inyandiko z'amashusho magufi (motivation / mindset content) yitwa **MPN**, bigenewe TikTok / Reels / YouTube Shorts.

Ntabwo ari ibice bikuwe mu ma-episode y'amateka (season1…season9) — ni ibintu bishasha, byandikwa ukwabyo, hakurikijwe iyi miterere:

- **Hook / Intro** — "Welcome back to MPN…" + ingingo y'uwo munsi
- **Points** (1, 2, 3…) — buri kimwe gifise umutwe n'amajambo magufi
- **CTA** (Call To Action) kuri nyuma
